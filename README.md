# Calculator

A simple and user-friendly calculator application.

## Overview

Calculator is a lightweight application designed to perform basic arithmetic operations in a clean and intuitive interface. It is intended to be fast, accurate, and easy to use for everyday calculations.

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, and division
- Decimal point support for fractional numbers
- Clear (C) and backspace functions to correct mistakes
- Keyboard input support
- Responsive layout that adapts to different screen sizes

## Getting Started

### Prerequisites

- A modern web browser (for the web version) / .NET runtime (for the desktop version)

### Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   cd Calculator
   ```

2. Open the project in your preferred IDE or build tool.

### Usage

1. Launch the application.
2. Enter numbers using the on-screen keypad or your keyboard.
3. Select an operation (+, -, *, /).
4. Press `=` to see the result.
5. Use `C` to clear the input or `⌫` to delete the last digit.
